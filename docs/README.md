# Documentação do projeto

Esta pasta registra material complementar ao código-fonte.

- `api/openapi.yaml`: especificação OpenAPI exportada por `mvn verify -Popenapi` enquanto a aplicação está rodando localmente; revisar e versionar atualizações quando a API mudar.
- `decisoes-fase1.md`: decisões relevantes de domínio, arquitetura e planejamento da Fase 1.
- `relatorio-cobertura/index.html`: relatório JaCoCo HTML arquivado da execução dos testes de 02/11/2026.
- `relatorio-cobertura/README.md`: resumo dos resultados e instruções para atualizar a evidência.
- `owasp/dependency-check-report.html`: relatório OWASP Dependency Check arquivado da execução de 01/11/2026 (também em JSON).
- `ddd/`: linguagem ubíqua e exportações do Miro (`event-storming.pdf` e `diagramas.pdf`).
- `Documentacao_DDD_Fase1.md`: documentação DDD do projeto.
